Teaching tools

Interactive simulations of problems in materials science. Each tool is named after the problem it simulates, and has the same layout: instructions for use, the tool, the physics of the problem, and a glossary. They run in any web browser, on a computer, tablet or phone.

Each tool is tagged with the courses it is most relevant to: UMT 205 Mechanical Properties of Materials, UMT 312T Mechanical Testing and Failure of Materials, MT 204 Structure and Properties of Materials, MT 209 Defects in Materials. Searching for a course code also finds its tools.
